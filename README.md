# Pad

A lightweight text and Markdown editor for macOS. Open it with a keyboard shortcut, write or edit a file, then return to your work.

- A compact, translucent writing window.
- Save, rename, share, and reopen text files.
- Configurable filenames and a choice of scratch or automatic saving.
- Independent Dock and menu bar controls.

Requires macOS 27. Pad is preparing for its first TestFlight release.
